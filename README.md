# Java Programming Lab – BCS351

This repository contains Java lab assignments for B.Tech CSE students.

## Course Details
- **Course:** Introduction to Programming Using Java Lab
- **Course Code:** BCS351
- **University:** Invertis University
- **Language:** Java
- **IDE:** Visual Studio Code
- **Total Assignments:** 15

## Topics Covered
1. Variables and Arithmetic
2. Decisions and Loops
3. Star and Number Patterns
4. Functions
5. Arrays
6. Reverse and Duplicates
7. Time Complexity
8. Matrices
9. Switch and ArrayList
10. Bubble and Selection Sort
11. Insertion Sort
12. Strings and Palindromes
13. Character Operations
14. StringBuilder Methods

## How to Run
1. Open the required question folder.
2. Compile the program:
   ```bash
   javac Main.java
   ```
3. Run the program:
   ```bash
   java Main
   ```

# Assignment 1: Hello World, Variables and Arithmetic

## 1. Aim
To print text, store values in variables and calculate with arithmetic operators.

## 2. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code)
- Java Extension Pack
- macOS Terminal
- Git and GitHub

## 3. Theory

Java is a high-level, object-oriented programming language.

This assignment covers the following basic concepts of Java:

- **System.out.println():** Used to display output on the console.
- **Variables:** Used to store data values.
- **Data Types:** Define the type of data stored in variables, such as int, double, char and String.
- **Arithmetic Operators:** Used to perform mathematical operations such as addition (+), subtraction (-), multiplication (*), division (/) and remainder (%).
- **final Keyword:** Used to declare constants whose values cannot be changed after initialization.

## 4. Algorithm / Procedure

### Question 1: Hello World

1. Start the program.
2. Create the main() method.
3. Print "Hello World" using System.out.println().
4. Print "Welcome to Java" on the next line.
5. Stop the program.

### Question 2: Variables and Data Types

1. Start the program.
2. Declare an integer variable roll with value 101.
3. Declare a double variable percentage with value 84.5.
4. Declare a character variable section with value 'B'.
5. Declare a String variable name with value "Asha".
6. Display all variable values with their respective labels.
7. Stop the program.

### Question 3: Arithmetic Operations

1. Start the program.
2. Declare two integer variables a = 17 and b = 5.
3. Calculate the sum using the addition operator (+).
4. Calculate the difference using the subtraction operator (-).
5. Calculate the product using the multiplication operator (*).
6. Calculate the quotient using the division operator (/).
7. Calculate the remainder using the modulus operator (%).
8. Display all the calculated results.
9. Stop the program.

### Question 4: Area and Perimeter of Circle

1. Start the program.
2. Declare a constant PI using the final keyword with value 3.14.
3. Declare an integer variable radius with value 7.
4. Calculate the area using the formula PI * radius * radius.
5. Calculate the perimeter using the formula 2 * PI * radius.
6. Display the area and perimeter.
7. Stop the program.

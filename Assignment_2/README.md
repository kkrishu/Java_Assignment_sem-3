## Aim
To use if, else if and loops to make decisions and repeat steps with whole numbers.

## Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code
- Java Extension Pack
- macOS Terminal
- Git and GitHub

## Theory

Decision-making statements and loops are important concepts in Java programming.

**1. if-else Statement:** Used to execute a block of code based on a condition.

**2. else-if Ladder:** Used to check multiple conditions and execute the corresponding block.

**3. Modulus Operator (%):** Returns the remainder after division. It can be used to check whether a number is even or odd.

**4. For Loop:** Used to execute a block of code repeatedly for a specified number of iterations.

**5. Logical Operators:** Operators such as `&&` (AND) and `||` (OR) are used to combine multiple conditions.

## Algorithm / Procedure

### Question 1: Check Even or Odd
1. Start the program.
2. Declare an integer variable `n = 27`.
3. Check whether `n % 2 == 0`.
4. If the condition is true, print that the number is even.
5. Otherwise, print that the number is odd.
6. Stop the program.

### Question 2: Grade Calculator
1. Start the program.
2. Declare an integer variable `marks = 83`.
3. Check if marks are greater than or equal to 90.
4. If true, print Grade A.
5. Otherwise, check if marks are greater than or equal to 75.
6. If true, print Grade B.
7. Otherwise, print Grade C.
8. Stop the program.

### Question 3: Leap Year Checker
1. Start the program.
2. Declare an integer variable `year = 2024`.
3. Check whether the year is divisible by 4 but not by 100, or divisible by 400.
4. If the condition is true, print "Leap year".
5. Otherwise, print "Not a leap year".
6. Stop the program.

### Question 4: Factorial Using For Loop
1. Start the program.
2. Declare an integer variable `number = 5`.
3. Initialize `factorial = 1`.
4. Use a for loop from 1 to the given number.
5. Multiply the factorial by the loop variable in each iteration.
6. Print the calculated factorial.
7. Stop the program.
